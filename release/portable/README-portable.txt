轻舟 SSH 便携版

1. 请先完整解压 ZIP，再运行 QingzhouSSH.exe。
2. portable.flag 必须与 QingzhouSSH.exe 放在同一目录，请勿删除或改名。
3. 所有应用数据会写入程序目录旁的 data 文件夹，不会默认写入 C 盘 AppData。
4. 日志下载、备份、更新临时文件和 WebView2 缓存也都位于该 data 文件夹内。
5. 升级前请先退出程序，并备份 data 文件夹。跨 Windows 用户或跨电脑复制后，受 DPAPI 保护的凭据需要重新录入。
6. 如需卸载便携版，请先备份需要的数据，再删除整个解压目录。

本工具不提供 SSH 交互终端；执行能力仅来自已审核的快捷任务、脚本和工作流。
