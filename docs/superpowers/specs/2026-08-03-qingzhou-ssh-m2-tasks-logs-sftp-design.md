# QingzhouSSH Milestone 2：快捷任务、日志与文件传输设计规格

- 状态：由已批准的总设计规格细化，准予实施
- 日期：2026-08-03
- 前置条件：Milestone 1 安全连接基础已通过测试

## 1. 目标与验收结果

Milestone 2 把现有“连接并识别服务器”的能力扩展为可完成实际工作的桌面工具。用户必须能够在不接触交互式终端的情况下完成系统状态检查、服务管理、日志检索和文件上传下载；高级用户可以执行受控的单条命令或多行脚本。

验收必须证明以下完整链路：

1. 从服务器页进入快捷任务，选择受支持的模板并填写类型化参数。
2. Rust 端重新校验参数、选择兼容实现、生成安全命令并流式执行。
3. UI 持续显示标准输出、标准错误、状态、耗时和取消结果。
4. 日志检索支持普通文本与 `.gz`，结果分页预览并可下载到数据根目录。
5. SFTP 上传和下载使用临时文件、流式读写与 SHA-256 校验。
6. 执行结果写入 SQLite；凭据、私钥、口令和敏感参数不会进入历史或诊断日志。

## 2. 范围

### 2.1 内置任务

首批模板包含：

- 系统概览：运行时间、负载、CPU、内存、磁盘、网络地址和进程摘要；
- 磁盘使用：挂载点、容量、已用空间和使用率；
- 进程查询：按名称过滤并限制结果数；
- 服务状态：读取 `systemd` 或传统 `service` 状态；
- 服务启动、停止和重启：危险操作，执行前二次确认；
- 日志检索：路径、关键词、时间范围、大小写、上下文行数和结果上限。

模板以版本化定义保存，兼容条件使用系统族、服务管理器、包管理器和命令能力组合，不按发行版名称复制整套模板。

### 2.2 高级命令与脚本

高级模式支持：

- 固定输入的单条命令；
- 带类型化参数的自定义命令；
- 多行 POSIX Shell 脚本。

每次执行必须展示目标服务器、超时、命令或脚本摘要和风险提示。它不是交互式终端，不支持持续 stdin、PTY 或全屏程序。脚本由受控的 `sh` 进程组执行，为 Milestone 3 的取消和恢复状态提供进程标识。

### 2.3 文件传输

- 单文件上传和下载；
- 本地路径必须位于用户明确选择的文件或数据根目录；
- 默认下载目录为 `<data-root>/downloads`；
- 远程路径必须是绝对路径且不能包含 NUL；
- 上传先写远程同目录临时文件，校验 SHA-256 后原子重命名；
- 下载先写本地 `.partial` 文件，校验后原子替换最终文件；
- 失败、取消或校验不一致时删除临时文件；
- 首版不实现目录同步、批量队列或双栏文件管理器。

## 3. 领域模型

### 3.1 任务定义

`TaskDefinition` 包含：

- `id`：稳定标识；
- `version`：正整数；
- `category`：`system`、`service`、`logs` 或 `advanced`；
- `title`、`description`、`riskLevel`；
- `compatibility`：系统族与能力谓词；
- `parameters`：字符串、整数、布尔、枚举、绝对路径、服务名与时间范围；
- `implementations`：按兼容谓词排序的命令实现；
- `outputKind`：文本、表格、键值或日志匹配。

普通模板参数只能经过类型对应的 Shell 转义器进入命令。模板中不存在可执行的未验证字符串插值。

### 3.2 执行记录

`ExecutionRecord` 包含：

- 执行标识、服务器标识、任务标识和模板版本；
- 状态：`queued`、`running`、`succeeded`、`failed`、`cancelled`、`uncertain`；
- 开始、结束和耗时；
- 退出码、错误分类和可重试标记；
- 已脱敏参数摘要、输出摘要和产生文件；
- 远程进程组标识（若存在）。

大输出不写入数据库。完整输出按执行标识流式写入 `<data-root>/logs/executions/<id>.log`，SQLite 只保存有限摘要和文件引用。

### 3.3 流事件

Tauri Channel 发送带序号的 `ExecutionEvent`：

- `started`：执行标识和开始时间；
- `stdout` / `stderr`：UTF-8 安全片段与累计字节数；
- `progress`：传输字节、总字节和百分比；
- `fileProduced`：相对数据根目录的文件引用与 SHA-256；
- `finished`：状态、退出码、耗时和结构化结果；
- `failed`：类型化错误与是否可重试。

事件序号单调递增。UI 忽略重复事件，并能在窗口重载后从执行历史恢复最终状态。

## 4. Rust 模块边界

### 4.1 模板与参数

`core/tasks` 负责定义解析、版本、兼容匹配、参数校验、Shell 单引号转义和命令渲染。它不建立 SSH 连接，不访问数据库。

### 4.2 SSH 执行

现有 `core/ssh/transport` 保留连接、主机指纹和认证职责。新增流式执行接口：

- 读取 SSH channel 的 stdout/stderr 并立即发送有界事件；
- 同时流式写入项目数据根目录日志；
- UI 事件单片不超过 32 KiB；
- 默认总输出上限 32 MiB，可由模板设置更小上限；
- 超限时终止读取并返回明确错误；
- 命令结束必须记录退出码；
- 取消结果区分已确认终止和远程状态不确定。

### 4.3 SFTP

`core/sftp` 建立在通过主机指纹验证和认证的 SSH 会话上，暴露单文件 `upload`、`download` 和 `hash_remote_file`。传输块大小固定为 64 KiB；哈希在流动过程中计算，不把整个文件读入内存。

### 4.4 日志检索

`core/logs` 负责：

- 校验绝对日志路径与检索参数；
- 根据扩展名选择 `grep` 或 `gzip -cd | grep` 的兼容命令；
- 使用固定的机器可解析记录分隔格式；
- 将匹配项解析为文件、行号、上下文、时间和文本；
- 对预览文本应用统一脱敏；
- 把结果保存为 UTF-8 JSON Lines 与用户可读文本文件；
- 通过游标读取分页结果，不重新执行远程命令。

日志结果上限默认 1,000 条、最大 10,000 条；上下文默认 2 行、最大 20 行；单次检索输出最大 32 MiB。

### 4.5 历史与脱敏

`core/redaction` 使用运行时敏感值集合和固定模式进行统一脱敏。任何凭据字段、私钥块、口令、密码参数和已标记敏感的模板参数在进入日志、数据库或 Tauri 事件前都必须替换为 `[REDACTED]`。

`repositories/execution_repository` 保存有限元数据并在应用启动时把遗留 `running` 记录改为 `uncertain`。数据库迁移新增任务定义、执行记录和产生文件表，不新增任何秘密列。

## 5. Tauri 命令边界

新增命令：

- `list_task_definitions(server_id)`；
- `start_task_execution(server_id, task_id, parameters, channel)`；
- `start_custom_execution(server_id, request, channel)`；
- `cancel_execution(execution_id)`；
- `search_logs(server_id, request, channel)`；
- `read_log_result_page(execution_id, cursor, page_size)`；
- `download_log_result(execution_id, suggested_name)`；
- `upload_file(server_id, request, channel)`；
- `download_file(server_id, request, channel)`；
- `list_executions(filter)`；
- `get_execution(execution_id)`。

所有命令只接受可序列化 DTO；不向 WebView 暴露文件句柄、SSH session、数据库连接或凭据引用内容。

## 6. 数据库迁移

`0002_tasks_and_executions.sql` 新增：

- `task_definitions`：内置或自定义定义、版本、启用状态和更新时间；
- `executions`：状态、时间、有限摘要、错误和远程进程组；
- `execution_files`：相对数据根路径、用途、大小和 SHA-256；
- `execution_parameters`：仅保存已脱敏显示值，敏感字段固定保存 `[REDACTED]`。

迁移使用外键和状态 CHECK 约束，可重复应用测试必须覆盖从 M1 数据库升级并保留服务器与主机密钥。

## 7. 界面与交互

应用主导航扩展为：首页、服务器、快捷任务、工作流、执行记录、下载文件和设置。Milestone 2 中“工作流”显示明确的下一里程碑说明，不伪装成可执行功能；其余 Milestone 2 页面必须工作。

### 7.1 快捷任务页

- 顶部选择服务器并显示系统兼容状态；
- 白银渐变任务卡按系统状态、服务管理和日志分类；
- 参数面板由定义生成，字段包含说明、默认值和约束；
- 危险任务在运行前弹出目标与影响确认；
- 运行抽屉实时显示状态、结构化结果和有限原始输出。

### 7.2 日志页

- 路径、关键词、时间范围、大小写、上下文和上限表单；
- 流式进度与匹配计数；
- 每页 50 条的虚拟化或分页预览；
- 结果文件下载按钮和保存位置反馈；
- 空结果、权限不足、缺少 `gzip`/`grep` 和超限均有明确状态。

### 7.3 文件与历史页

- 上传/下载表单显示本地路径、远程路径、字节进度、速度和校验状态；
- 下载文件页列出数据根目录内产生文件，不扫描用户未授权目录；
- 执行记录可按服务器、任务类型、状态和时间筛选；
- 详情展示参数摘要、时间线、退出码、结构化结果、脱敏日志和文件。

视觉继续使用已批准的白银渐变、边缘高光和三层阴影；正文保持高对比度，不为新增页面引入第二套设计语言。

## 8. 错误、安全与资源限制

- 所有路径、服务名、数字和枚举在 Rust 侧再次验证；
- 普通模板不允许用户提供原始 Shell 片段；
- 高级脚本执行前必须二次确认；
- 主机指纹变化在任何命令或 SFTP 认证前拦截；
- 凭据解密仅存在于建立连接所需的局部作用域并尽快清理；
- 数据库摘要最大 8 KiB，UI 单事件最大 32 KiB，完整输出最大 32 MiB；
- 文件传输校验失败即删除临时文件；
- 磁盘空间不足、权限不足、网络中断和超时使用独立错误类别；
- 取消无法确认远程进程状态时保存为 `uncertain`，UI 不显示“取消成功”。

## 9. 测试与里程碑门槛

自动化覆盖：

- 参数边界、Shell 转义、兼容匹配和模板版本；
- 事件顺序、UTF-8 分片、输出上限、退出码和脱敏 canary；
- M1 到 M2 数据库迁移与执行状态恢复；
- `.log`、`.gz`、大小写、上下文、上限和分页；
- SFTP 上传、下载、网络中断、临时文件清理和哈希不一致；
- 密码与私钥服务器上的任务、日志和传输真实集成测试；
- React 参数表单、危险确认、流式结果、分页、传输与历史筛选；
- D 盘路径审计和凭据 canary 全仓扫描。

Milestone 2 完成门槛：三类内置任务、高级命令/脚本、日志检索下载和 SFTP 在受控 SSH 夹具上完成 UI → Rust 校验 → SSH/SFTP → 结构化结果 → 历史/下载闭环；全部测试通过，且日志和数据库中不存在秘密 canary。

## 10. 非目标

本里程碑不实现工作流图执行、条件分支、恢复点、安装包和在线更新；这些功能分别由 Milestone 3 和 Milestone 4 实现。本里程碑必须提供稳定的任务、执行、传输和历史接口供后续复用，不能预先塞入不可测试的工作流占位实现。
