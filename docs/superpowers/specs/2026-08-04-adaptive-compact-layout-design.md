# 自适应紧凑布局设计

日期：2026-08-04

## 背景

当前客户端在窗口缩小时主要压缩可用布局宽度，但卡片、间距、侧栏和部分页面的固定最小宽度仍按大窗口设计保留，导致卡片互相挤压、内容溢出或需要横向滚动。

本次选择方案 B：自适应紧凑模式。客户端根据实际内容宽度自动降低界面密度，并在极窄窗口重新排列布局；不使用整页 `zoom` 或 `transform: scale()` 缩放。

## 目标

- 窗口缩小时，卡片、间距、图标、侧栏和阴影同步适度缩小。
- 文字、输入框和按钮保持清晰、易读、易点击。
- 页面在 960×640 最小窗口内不出现整体横向挤压。
- 保留现有白银渐变、立体卡片和较强阴影风格。
- 不改变业务功能、数据存储位置、SSH/SFTP 行为或在线更新逻辑。

## 三档响应规则

### 标准模式：宽度不小于 1360px

- 保持当前视觉尺寸和页面结构。
- 左侧导航保持完整宽度和纵向排列。
- 首页、服务器和任务卡片使用当前多列布局。
- 数据目录徽章正常显示，并在空间不足时截断路径。

### 紧凑模式：1050px 至 1359px

- 页面外边距、卡片内边距和卡片间距缩小约 10%–15%。
- 左侧导航宽度由 224px 缩减到约 180–196px，导航按钮高度和图标同步适度缩小。
- 卡片圆角和阴影扩散范围同步缩小，但保留白银渐变和立体层次。
- 标题和正文字号仅轻微缩小，并设置可读下限；不与卡片按相同比例缩放。
- 数据目录徽章限制最大宽度，通过省略号和悬停完整路径保留信息。
- 页面网格优先缩小卡片和间距；达到单卡可读下限后才减少列数。

### 最小模式：960px 至 1049px

- 左侧纵向导航转换为顶部横向导航，保留图标和中文文字，不使用仅图标菜单。
- 横向导航允许自身滚动，但正文区域不产生整体横向滚动。
- 多列卡片根据页面容器宽度转换为双列或单列。
- 表单标签、输入框和操作按钮自动换行；输入框不被压缩到无法读写。
- 数据目录徽章进一步缩短，仅保留图标和尾部路径摘要，完整路径继续通过提示查看。
- 窗口控制按钮和整个蓝色顶栏拖动能力保持不变。

## 尺寸与可用性下限

- 客户端最小窗口保持 960×640。
- 正文视觉字号不低于 12px，主要表单和操作文字优先不低于 13px。
- 主要按钮和输入框高度不低于 36px。
- 卡片内部正文不得因缩放产生文字重叠或裁切。
- 页面级容器不得依赖会突破最小窗口的固定 `min-width`。

## 页面适配

### 首页、服务器与快捷任务

- 首页操作卡和推荐流程跟随页面容器缩小间距和内边距。
- 服务器卡、任务卡在紧凑模式保留多列，在单卡宽度不足时自动减少列数。
- 卡片说明文字允许自然换行，不使用缩放隐藏正文。

### 日志检索

- 搜索条件与结果区域优先按比例调整列宽。
- 最小模式下搜索条件置于结果上方，避免左右区域互相挤压。
- 表格保留内部滚动能力，页面本身不横向溢出。

### 文件传输

- 继续使用页面容器查询适配实际正文宽度。
- 紧凑模式下缩小双栏卡片内边距与中间操作区宽度。
- 最小模式下本地目录、传输操作、远程目录按完整流程纵向排列。

### 工作流

- 移除当前依赖 850px 固定最小宽度的页面级布局限制。
- 紧凑模式同步缩小步骤库、画布和检查器宽度及间距。
- 最小模式采用步骤库、画布、检查器分区排列；画布内部可以平移，外层页面不得整体横向溢出。
- 运行记录、风险确认和节点时间线根据容器宽度减少列数。

### 设置、下载与执行记录

- 表单和详情卡缩小间距并按可用宽度换列。
- 长路径和标识符使用省略号与完整提示，不能撑破卡片。

## 实现边界

- 使用 CSS 自定义属性统一控制标准与紧凑密度，例如页面间距、卡片间距、卡片内边距、导航宽度和阴影尺寸。
- 使用媒体查询控制客户端整体密度档位。
- 使用容器查询控制日志、文件传输、工作流等页面内部结构。
- 不通过 JavaScript监听窗口宽度来重复实现 CSS 布局逻辑。
- 不使用浏览器缩放、WebView 缩放或整页变换实现紧凑模式。

## 验收标准

- 1920×1080：保持当前标准视觉效果。
- 1366×768：进入紧凑模式，卡片、间距和侧栏同步缩小，无明显空白浪费。
- 1180×760：紧凑模式下主要页面不挤压、不重叠，卡片文字完整可读。
- 960×640：进入最小模式，导航转为顶部横向布局，正文无整体横向溢出。
- 首页、服务器、快捷任务、日志检索、文件传输、工作流、执行记录、下载文件和设置均通过对应尺寸的布局检查。
- 窗口拖动、最小化、最大化和关闭行为不回退。
- 所有现有前端、Rust 和桌面路径契约测试继续通过。
- 仅在用户确认后生成下一份本地测试包；不自动发布或更新。

## 非目标

- 本次不重新设计颜色、图标或卡片立体风格。
- 本次不新增侧栏折叠开关或手动密度设置。
- 本次不改变最小窗口尺寸。
- 本次不修改任何服务器功能或远程命令实现。
