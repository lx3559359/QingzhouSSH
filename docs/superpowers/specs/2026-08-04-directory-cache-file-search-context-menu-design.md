# 目录缓存、文件名搜索与安全右键菜单设计

## 目标

面向不熟悉 Linux 的用户，减少远程目录重复读取造成的等待，并让用户可以通过部分文件名找到远程文件，同时为文件、文件夹和日志结果提供符合桌面客户端习惯的安全右键操作。

本轮保持版本 `0.1.5`，只生成本地测试包，不提交、不推送、不创建标签，也不发布到 GitHub 或魔塔。

## 已确认范围

- 采用客户端统一会话缓存；缓存只在本次客户端运行期间有效。
- 日志页增加独立的“找文件名”模式，不与日志内容结果混合。
- 右键菜单只覆盖文件、文件夹、文件名搜索结果和日志内容结果。
- 右键菜单只提供安全操作，不提供新建、重命名或删除。
- 所有应用数据继续保存在 D 盘项目目录或便携包自身的 `data` 目录中。

## 根因

当前主界面通过条件渲染切换页面。离开文件传输页后，页面组件及其目录状态会被销毁；再次进入时会重新读取本地目录、服务器列表和远程根目录。

远程目录读取的每次调用还会重新建立 SSH 连接、打开 SFTP 子系统、读取目录、关闭 SFTP 并断开 SSH。因此重复访问同一路径仍会发生完整网络往返，用户会持续看到“正在读取远程目录”。

当前智能日志检索只有一个 `keyword`，该值始终用于匹配文件内容。智能模式虽然会先发现候选日志文件，但不返回只匹配文件名的结果，所以输入 `requi` 仍然会在日志正文中查找并可能产生大量内容结果。

## 总体架构

### 1. 统一目录会话缓存

新增前端目录缓存模块，负责本地目录和远程目录的读取、复用、失效以及当前路径记忆。缓存位于客户端内存，不写入磁盘。

远程缓存键由 `serverId + normalizedPath` 组成；本地缓存键由规范化绝对路径组成。缓存值包括目录列表、成功读取时间和当前读取中的 Promise。并发请求同一个目录时复用同一个 Promise，避免重复建立连接。

缓存模块提供以下行为：

- `getLocal(path)`：有缓存时立即返回；无缓存时读取并保存。
- `getRemote(serverId, path)`：有缓存时立即返回；无缓存时读取并保存。
- `refreshLocal(path)` / `refreshRemote(serverId, path)`：保留界面上的旧列表，强制重新读取并替换缓存。
- `invalidateLocal(path)` / `invalidateRemote(serverId, path)`：让指定目录在下一次访问时重新读取。
- `rememberRemotePath(serverId, path)`：记录每台服务器最后访问的目录。
- `clearServer(serverId)`：服务器配置或身份信息变化后清理对应缓存。

文件传输页和远程日志选择窗口使用同一个缓存实例。页面重新挂载时，已访问目录可立即显示，不出现空白加载态。

### 2. 远程文件名搜索

在日志检索请求中增加明确的搜索目标：

- `content`：保持现有日志内容检索。
- `filename`：只按远程文件名模糊搜索。

文件名搜索使用不区分大小写的字面包含匹配。例如输入 `requi` 可以匹配 `requirements.txt`。不支持用户输入任意 Shell 通配符或正则表达式，避免小白误操作和命令注入风险。

后端只搜索固定根目录 `/var/log`、`/opt`、`/srv`、`/home`，最大深度为 6，忽略无权访问的目录，不扫描 `/`。结果最多返回 200 个普通文件，并受现有 SSH 执行超时和输出上限约束。

文件名结果是独立的数据结构，包含：

- 完整路径
- 文件名
- 文件大小（远端可提供时）
- 修改时间（远端可提供时）

文件名搜索不读取文件内容，也不生成上下文行。用户可通过结果右键菜单选择“搜索文件内容”，客户端随后切换到内容检索、使用精确文件路径并预填原关键词。

### 3. 安全上下文菜单

新增统一的 `ContextMenu` 组件和动作描述模型。业务页面只提供当前对象可执行的动作，组件负责定位、焦点和关闭行为。

菜单通过鼠标右键、键盘菜单键或 `Shift+F10` 打开。点击菜单外、按 `Esc`、切换页面或开始执行动作时关闭。靠近窗口右侧或底部时，菜单自动向内调整，不能超出可视区域。

动作范围如下：

| 对象 | 右键动作 |
| --- | --- |
| 本地文件 | 上传到当前远程目录、复制文件名、复制完整路径 |
| 本地文件夹 | 打开、刷新该目录、复制完整路径 |
| 远程文件 | 下载到项目目录、搜索文件内容、复制文件名、复制完整路径 |
| 远程文件夹 | 打开、刷新该目录、复制完整路径 |
| 文件名搜索结果 | 下载到项目目录、搜索文件内容、复制完整路径 |
| 日志内容结果 | 复制该行内容、复制日志文件路径 |

上传或下载条件不满足时，相关动作显示为禁用状态并提供简短原因，例如“请先选择目标服务器”或“远程目录尚未读取完成”。

复制操作使用系统剪贴板 API。成功后显示短暂的中文提示，不弹出阻塞式对话框。

## 用户交互

### 目录浏览

1. 用户首次打开某个目录时显示完整加载状态。
2. 用户返回已经访问过的目录时立即显示缓存列表。
3. 用户点击“刷新”时保留当前列表，只在路径栏显示小型刷新动画。
4. 刷新成功后替换列表；刷新失败时继续保留旧列表，并提示“显示的是上次读取结果”。
5. 上传成功后强制刷新远程目标目录。
6. 下载成功后强制刷新本地下载目录。
7. 切换服务器时恢复该服务器本次会话最后访问的路径；如果没有记录则进入 `/`。

### 文件名搜索

日志检索页增加“搜日志内容 / 找文件名”分段选择，默认保持“搜日志内容”。

选择“找文件名”后：

- 输入框标签改为“文件名包含”。
- 示例改为“例如：requi、access、订单”。
- 隐藏上下文行数、时间范围和区分大小写等只适用于内容的选项。
- 显示固定安全搜索范围说明。
- 结果区域改为文件表格，不与日志行分页混合。

无结果时显示“没有找到名称包含该内容的文件”，并建议缩短关键词或检查服务器权限。

## 数据流

### 目录读取

1. 页面向目录缓存请求指定路径。
2. 缓存命中时同步提供旧列表，页面立即渲染。
3. 缓存未命中或用户强制刷新时调用现有目录读取 API。
4. API 完成后更新缓存和页面。
5. 上传、下载或服务器配置变化时精确失效相关键。

### 文件名搜索

1. 前端提交 `target: filename` 和经过长度校验的关键词。
2. Rust 校验请求，构造固定根目录、固定深度和固定结果上限的 `find` 命令。
3. 远端输出机器可解析记录，不包含任意用户命令片段。
4. Rust 解析并保存结果，前端按页读取文件记录。
5. 下载或“搜索文件内容”复用现有受控下载和精确日志检索流程。

## 错误处理

- 缓存命中但后台刷新失败：保留缓存并标明结果可能不是最新。
- 首次目录读取失败：显示中文原因和“重试”入口，不显示空白列表。
- 文件名搜索缺少 `find`：提示“服务器缺少文件查找命令，无法按文件名搜索”。
- 搜索超时：提示缩短关键词或缩小范围，技术详情折叠显示。
- 权限不足：保留其他可访问目录的结果；完全无结果时说明可能受权限限制。
- 剪贴板写入失败：显示“复制失败，请重试”，不泄露路径之外的系统信息。

## 安全与性能约束

- 不执行用户提供的 Shell、正则或通配符表达式。
- 文件名关键词最大 256 字节，拒绝空值和 NUL 字符。
- 远程文件名搜索不扫描根目录 `/`，最大深度 6，最多返回 200 个普通文件。
- 目录缓存最多保存 128 个目录，按最近最少使用方式淘汰，避免长时间运行造成内存增长。
- 缓存不保存凭据、SSH 会话或文件内容。
- 右键菜单不包含删除、重命名、新建或覆盖确认绕过操作。

## 测试与验收

### 自动化测试

- 同一服务器和路径连续访问只调用一次远程目录 API。
- 返回上级目录时缓存立即显示，不出现全屏加载态。
- 手动刷新强制调用 API，并在失败时保留旧列表。
- 上传和下载成功后只刷新受影响目录。
- 不同服务器的相同路径使用不同缓存键。
- 文件名搜索请求使用 `target: filename`，不会进入内容 grep 流程。
- `requi` 可以匹配 `requirements.txt`，默认不区分大小写。
- 文件名搜索命令不包含 `find /`，深度和结果数量受限。
- 每种对象只显示设计表格中允许的右键动作。
- 点击外部、按 `Esc` 和执行动作后菜单关闭。
- 右键菜单支持键盘打开和焦点返回。

### 人工验收

1. 打开远程 `/home`，切换到其他页面再返回，目录立即显示且不出现大面积“正在读取”。
2. 进入子目录后返回 `/home`，不重新发起读取；点击“刷新”才重新读取。
3. 在文件名模式输入 `requi`，结果出现 `requirements.txt`，而不是几千条日志正文。
4. 右键远程文件可以下载、搜索内容和复制路径。
5. 右键本地文件可以上传和复制路径。
6. 右键日志结果可以复制该行和日志路径。
7. 菜单在窗口四个边缘均不会超出客户端范围。

## 非目标

- 不持久化远程目录缓存。
- 不保持长期 SSH/SFTP 连接池。
- 不提供全盘或根目录文件扫描。
- 不提供删除、重命名、新建、移动和批量操作。
- 不为导航栏、空白区域或普通卡片添加右键菜单。
