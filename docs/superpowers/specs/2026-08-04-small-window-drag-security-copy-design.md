# 小窗口拖动与安全提示优化设计

日期：2026-08-04

## 目标

修复客户端窗口缩小后顶栏难以拖动的问题，并简化左侧导航底部在小窗口下显得拥挤、技术化的安全状态文案。

## 已确认方案

采用方案 1：

- 整条蓝色顶栏均作为窗口拖动区域，但最小化、最大化和关闭按钮保持正常点击，不触发拖动。
- 不再依赖被路径徽章挤压的单独拖动区域；由客户端显式请求原生窗口拖动。
- 左侧导航底部保留绿色状态点，将两行“本地安全模式 / 凭据不会进入 WebView”改为单行“本地安全保护已开启”。
- 不改变页面功能、导航结构、数据目录和现有视觉主题。

## 交互规则

- 在蓝色顶栏任意非窗口控制按钮区域按住鼠标左键，可移动窗口。
- 点击最小化、最大化或关闭按钮时，只执行对应窗口操作。
- 非鼠标左键操作不触发窗口拖动。
- 小窗口状态下仍保留数据目录提示，但它所在的顶栏区域也可以用于拖动。

## 验证标准

- 前端测试覆盖顶栏拖动调用和窗口控制按钮隔离。
- 桌面权限检查包含原生窗口拖动权限。
- 左侧状态只显示“本地安全保护已开启”，不再出现“WebView”。
- 完整前端、Rust 与桌面构建检查通过。
- 仅生成新的本地 r6 测试包，等待用户自行验证，不发布、不自动更新。
