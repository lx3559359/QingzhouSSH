# 用户指南

## 1. 第一次启动与数据目录

第一次启动会要求选择数据根目录。请选择有足够空间、当前系统用户可读写且便于备份的位置。Windows 便携版通过程序旁的 `portable.flag` 自动使用同目录 `data`，不会再显示选择页。

应用业务数据不会默认写入 AppData。目录布局、迁移和备份见 [数据与更新](data-and-updates.md)。

## 2. 添加服务器与 Host key（主机指纹）

在“服务器”页添加名称、主机、端口、用户名和认证方式。密码、私钥内容和私钥口令在 Windows 进入 DPAPI 用户级保险库，在 macOS/Linux 进入系统 Keychain/Secret Service；界面与数据库只保存凭据引用。系统密钥环不可用或未解锁时，客户端会明确阻断凭据写入或读取，不会降级为明文文件。

第一次连接只获取 Host key 指纹，不发送密码或私钥签名。请通过服务器控制台、云平台或管理员提供的可信渠道核对 SHA-256 指纹，再点击批准。以后指纹改变时连接会在认证前终止；先查明服务器是否重装、地址是否复用或网络是否被劫持，不要盲目重新信任。

连接成功后，工具会自动探测系统、包管理器、服务管理器、架构和可用命令，并据此启用功能。

## 3. Quick tasks（快捷任务）

任务页提供系统概览、磁盘使用、进程查询、服务状态、启动、停止、重启和日志相关任务。工具会根据远端 Linux/BSD/Windows 系统族、Shell、服务管理器与实际命令能力选择固定适配器；无法满足条件的任务会说明原因，不会猜测命令。填写参数后先核对目标服务器和命令摘要。

服务启停、自定义命令和多行脚本属于 **Dangerous actions**，必须二次确认。个人脚本可显式选择 Bash、POSIX sh 或 PowerShell；执行前会核对远端能力，并把参数映射为受控的 `QZ_PARAM_*` 环境变量。高级执行仍是一次性非交互命令，不提供 PTY 或持续 stdin；需要回答提示、打开编辑器或运行全屏 TUI 的命令不适用。

## 4. Log search and download（日志检索与下载）

1. 选择服务器，填写远端绝对日志路径、关键词、上下文行数和最大结果数。
2. 普通 `.log` 与 `.gz` 均可检索；结果按每页 50 条显示，后端使用游标继续读取。
3. 预览确认后点击下载。文件写入 `<数据根目录>\downloads`，先使用 `.partial`，完成后校验 SHA-256 并原子改名。
4. 下载列表只展示后端登记的相对路径，不接受前端传入任意本地绝对路径。

关键词过宽、日志过大或远端工具缺失时，请缩小时间/关键词范围，或先用系统能力页面确认 `grep`、`gzip` 和 `awk`。

## 5. SFTP 文件传输

页面保留每台服务器最后访问的远端目录，切换目录会优先显示短期缓存并在后台刷新；服务器切换或较慢旧请求返回时，不会覆盖当前服务器的列表。POSIX 远端从 `/` 导航，Windows OpenSSH SFTP 可从盘符根（如 `C:/`）导航。

上传前选择本地文件和右侧远端目录；覆盖文件必须明确确认。下载固定进入数据根的 `downloads`。任务会写入持久传输队列，应用重新打开后仍可看到结果；全局最多三个工作器，同一服务器最多两个活动传输，避免单台服务器或大量文件拖垮界面。可取消排队或活动传输；临时网络故障只做有限自动重试，失败或状态不确定且仍可重试时，界面提供手工重试。

上传和下载使用有界流水线与独立 SFTP 通道，状态分为连接、传输、校验和完成整理，并显示当前速度、平均速度与预计剩余时间。默认“均衡校验”优先调用探测到的固定远端 SHA-256 命令；远端没有安全可用的哈希命令时，以 SSH 传输完整性和文件大小完成校验，不再额外重读整份文件。工作流恢复点等严格场景会在必要时通过 SFTP 重读计算远端 SHA-256。

远端列表支持新建文件夹、文件或文件夹重命名、删除普通文件和删除空文件夹。所有名称必须是单个路径段；根目录、符号链接、特殊对象、非空目录和类型变化都会被拒绝，重命名不会覆盖已有对象。

取消只表示本地执行通道已确认停止。无法确认远端状态时记录为 `uncertain`，不要把它当作成功或安全失败；先检查远端临时文件和最终文件。

## 6. Workflow（可视化工作流）

工作流可组合开始、快捷任务、自定义命令/脚本、上传、下载、日志检索、条件和停止节点。每个定义只能有一个开始节点，图必须可达、无环，条件节点必须各有一条 true/false 分支。

- 保存会创建不可变版本，已经开始的运行继续引用旧版本。
- 节点串行执行；可重试失败会暂停，重试只创建当前节点的新 attempt。
- 上传覆盖可在 `<数据根目录>\backups\workflows` 创建恢复点。
- 回滚需要二次确认，并按成功变更的逆序恢复；任何无法确认的步骤都不会误报成功。
- 诊断包写入 `downloads`，包含脱敏时间线、错误和恢复元数据，不包含凭据、脚本文本或任意本地绝对路径。

## 7. 历史、取消与 uncertain

历史页可按服务器、任务和状态筛选。`cancelled` 只用于已经确认执行通道终止的情况；应用崩溃、网络断开或远端进程状态不明时使用 `uncertain`。恢复操作前先到服务器核对实际状态。

## 8. 设置与在线更新

设置页显示当前版本、数据根、上次检查结果和实际使用的更新源。GitHub 是主源；只有网络错误、404 或服务端错误才尝试 ModelScope。主源返回格式或安全错误时会直接阻断，不用镜像掩盖风险。清单只接受当前客户端对应的平台键，不能把其他系统或架构的包当作更新安装。

检查、下载和安装都由用户明确触发。下载完成后必须通过 Tauri 更新签名、SHA-256 和大小校验；安装确认会说明应用即将退出。工具不静默安装，也不自动重启正在执行的任务。

## 9. 故障排查

- 无法连接：检查主机、端口、防火墙、账号和服务器 SSH 服务，不要关闭主机指纹校验。
- 任务不可用：查看系统能力探测结果，确认远端命令与账号权限。
- 日志无结果：确认路径为远端绝对 `.log`/`.gz` 路径，并缩小关键词。
- 更新被拒绝：不要绕过签名或手工替换清单；从官方双源重新下载并核对 `SHA256SUMS`。
- 数据目录移动后凭据不可用：Windows DPAPI 绑定用户和电脑；macOS/Linux 凭据保存在系统密钥环且不随数据目录复制。跨用户、跨电脑或密钥环条目缺失时需要重新录入。
